# Q1.1: Syntactic restrictions for decidable implication

Parent question: [Q1: Complexity of implication for disjunctions of dependence atoms](Q1.md).

## Question

Which syntactic restrictions on the premises and consequent guarantee
decidability of implication for disjunctions of dependence atoms?

The value domain remains unrestricted. Restrictions should specify a
class of input formulas for the implication problem in Q1. Finite-team
and unrestricted implication coincide on these fragments as well.

[Q1.2](Q1.2.md) asks which restrictions additionally guarantee polynomial-time
decidability.
